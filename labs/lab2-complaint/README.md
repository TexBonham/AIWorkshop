# Lab 2: The complaint

## The complaint

> **From a student, via the feedback form**
>
> The search on the events page is broken. I typed **art** and got *Startup Weekend* and *Cartography Club*. Neither of those has anything to do with art. The actual *Art Society Open Studio* was in the list, but so was a bunch of junk.

Notice: **every test currently passes.** Nothing is "broken" in the sense of Lab 1. The code does exactly what it was written to do; it just wasn't written to do what people expect. Your job is to decide what the search *should* do, write that down as examples, and only then get it built.

## Files

| File | What it is | Edit it? |
|---|---|:-:|
| `index.html` | The campus events page with search, tag filter and sorting. Double-click to open. | no |
| `app.js` | The logic. **This is the only file you change.** | **yes** |
| `tests.html` | Runs the tests and shows green/red. | no |
| `tests.js` | The tests. You'll ask Claude to **add** tests for the new behaviour at the end; paste them in here. | at the end |

## Done when

- Your written examples (the spec) all behave as you said.
- The acceptance checklist the instructor reveals mid-lab all passes.
- Existing tests still pass, and there is at least one new test for the new behaviour.
